고려대학교 의료정보학 박사과정 정인용의 연구 홈페이지입니다. "우리가 측정한 것은 정말 알고자 했던 것인가"라는 질문을 따라 논문을 정리하고, 각 논문을 직접 눌러 보는 해설 글로 풀었습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 홈. 머리말, 한 눈금 위의 모든 연구, 연구 도록(질문별/주제별 색인과 상세), 소개, 논문 전체 목록, 수상과 과제, 배운 말, 연락 |

| `assets/site.js` | 글 공통 부품: 결론 블록, 수치 짐작해 보기, 이어지는 연구, 눈금 점 말풍선 |
| `assets/site.css` | 공통 디자인 시스템 |
| `DESIGN.md` | 디자인 계약서. 새 페이지를 만들기 전에 먼저 읽기 |
| `.claude/skills/` | 디자인 점검 스킬(design-pick, avoid-ai-design, antislop 등, MIT) |

## 새 논문 추가하기

1. `posts/llm-psychometrics.html`을 본보기로 새 해설 글을 만듭니다. 머리의 `<link>`, 상단 바, 끝의 두 `<script>`를 그대로 둡니다.
2. `assets/catalog.js`의 `POSTS`에 항목을 하나 추가합니다(`slug`, `q`, `concl`, `val`, `unit`, `cap`, `g`). 프리프린트라면 `preprint:true`를 넣습니다.
3. 같은 파일의 `P`(논문 목록)에서 해당 논문의 마지막 칸에 `'posts/새-글.html'`을 넣습니다.
4. 필요하면 `TOPICS`의 주제 목록에 slug를 추가합니다.

홈의 색인, 한 눈금 그림, 결론 블록, 연결 섹션은 이 데이터로 자동으로 만들어집니다.

## 공개

GitHub 저장소의 **Settings → Pages**에서 배포할 브랜치와 `/ (root)`를 고르면, 그 브랜치에 푸시할 때마다 1~2분 뒤 자동으로 반영됩니다.

## 출처

각 해설 글의 꼬리에 원문 인용, DOI, 라이선스를 적었습니다. 수치는 원문의 표와 본문에서 가져왔고, '가상 예시', '시뮬레이션'으로 표시한 부분은 이해를 돕기 위해 만든 것입니다. 프리프린트는 동료 심사 전이며 내용이 바뀔 수 있습니다.
